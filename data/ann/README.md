# ANN-Benchmarks Data

Place the ANN-Benchmarks HDF5 files used by the WF-IoT static experiment in this directory before running the full static config.

Required files:

- `sift-128-euclidean.hdf5`
- `glove-100-angular.hdf5`
- `lastfm-64-dot.hdf5`
- `fashion-mnist-784-euclidean.hdf5`
- `nytimes-256-angular.hdf5`

These datasets are intentionally not bundled in the release archive.
